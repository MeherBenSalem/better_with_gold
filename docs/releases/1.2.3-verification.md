# Better With Gold 1.2.3 verification

Verified locally on 2026-10-02. All nine production jars built and passed real client startup checks.

## Crash causes and fixes

- Minecraft 26.2/26.3 required the item registry ID before construction. Constructors now receive initialized properties.
- Forge/NeoForge resolved deferred entries before their registry event. Items and tabs now register during the matching event.
- The MultiLoader conversion omitted models and textures. Original assets are restored.
- Equipped reinforced armor selected vanilla gold textures on newer versions. Custom material layers/equipment assets now select the original reinforced armor textures; Fabric 1.20.1 has a dedicated renderer hook.
- Removed the unused required JAuml dependency. Fabric API remains required and is declared on both publishing platforms.

## Client checks

Tests used isolated game directories and the actual release jars, with required Fabric API versions from each workspace. Each test checked a current title screen or loaded world stable for ten seconds, all 17 registry IDs, and four armor texture bindings. Every client exited normally with code 0.
