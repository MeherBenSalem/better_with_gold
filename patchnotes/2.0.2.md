# Remnants | Fellowship 2.0.2

A click fix for Minecraft 26.3.

## Fixed (Minecraft 26.3)

- **The roster ignored clicks.** Its tabs, the sellsword list and the action buttons did nothing when clicked, and
  clicking outside the panel did not close it. All of them respond to left-click again.

Minecraft 26.3 numbers mouse buttons differently from earlier versions (left is 1, right is 3), and the roster read
the raw number. It now translates it the same way Minecraft's own inventory screens do. 1.20.1, 1.21.1 and 26.2 are
unchanged apart from the version number. No gameplay, config or save changes.
