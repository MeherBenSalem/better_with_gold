# Remnants | Fellowship 2.0.1

A packaging fix for every version.

## Fixes

- **The jar no longer contains a file with `|` in its name.** The bundled licence was stored as
  `LICENSE_Remnants | Fellowship`. `|` is not allowed in file names on Windows, Android and some other
  storage, so anything that unpacks or scans the jar there could fail with "Cannot open output file ...
  Operation not permitted". The licence is now `LICENSE_better_with_gold`.

No gameplay, config or save changes.
